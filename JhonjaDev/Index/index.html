Sobre mí

Construyo la web que tu negocio necesita, no la que sobra en una plantilla

Soy desarrollador y diseñador web. Trabajo directamente con cada cliente para entender el negocio antes de escribir una sola línea de código: quién es su cliente ideal, qué necesita mostrar primero y qué acción quiero que tome al llegar a la página.

Me apasiona el detalle — una animación que se siente natural, un botón que responde bien al toque, una carga rápida en el celular. Eso es lo que separa una web que solo existe de una que realmente genera resultados.

Trabajo con HTML, CSS y JavaScript puro para sitios livianos y rápidos, y con Supabase cuando el proyecto necesita base de datos, formularios conectados o un panel de administración.
